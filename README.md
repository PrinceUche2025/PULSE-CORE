**PULSE-CORE**


Hey everyone! I Built this project because I wanted a fitness app that did not look like every other generic tracker out there. I went for a bit of a cyberpunk terminal / athletic-tech vibe blending high-energy photography with real data telemetry.


**What it does**

**Live Workout Execution**: You can actually run through routines step by step, check off sets as you crush them, and log your exact numbers.
Mission Control Dashboard: Tracks your completed sessions, total volume load (in KG), and consistency streaks with interactive SVG telemetry rings.

**Custom Protocol Library**: Pre built routines broken down by muscle groups and intensity levels (Beginner, Intermediate, Advanced), plus the ability to build your own custom workouts.

**Dark & Light Themes**: Fully supported theme switcher so it looks clean whether you're coding in a dark room or working in bright daylight.

**Local Storage & Backup**: Everything is stored right in your browser. You can export or restore your workout history as a JSON file anytime.

*Tech Stack*
*React 18 + TypeScript*
*Tailwind CSS for styling*
*Lucide React for icons*
*Vite for lightning fast bundling*
